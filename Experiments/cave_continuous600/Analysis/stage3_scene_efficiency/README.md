# CAVE V3-stage3 逐场景与效率分析

逐场景：seed42/43/44，12个场景，×4/×8。先计算同种子的Stage3-baseline差值，再对3个种子取均值。正PSNR、负SAM/ERGAS表示改善。per_scene_comparison.csv保留每种模型的均值及配对差值样本标准差。

×4：11/12场景PSNR改善，12/12 SAM改善，10/12 ERGAS改善，10/12三项同时改善。×8：9/12、12/12、10/12，9/12三项同时改善。不能据此声称所有场景、所有种子均改善：各场景在3种子中每次PSNR均改善的数量，×4为6/12，×8为7/12。

效率：RTX3060Ti，batch1，HR256×256，FP32且TF32关闭，eval/inference_mode，10次预热，3组各10次测量共30次；CUDA event中位数。固定seed42的三种已训练权重。输入为随机张量，不含I/O或CPU-GPU传输，未测训练速度、FLOPs或512×512全图速度。峰值为PyTorch allocated显存，非nvidia-smi进程总显存。

注册参数包含禁用分支；前向使用参数通过CPU梯度存在性计数（包括梯度值为0但参与图的参数）。Stage3仍注册完整V3的分支，因此注册参数未减少。
