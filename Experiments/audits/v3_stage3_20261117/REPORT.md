# V3-stage3 模型与训练审计

核查日期：2026-11-17。核查方式：源码审阅、日志与 checkpoint 一致性核对、CPU/GPU 前向反向实测、正式入口的完整测试图像复测。

## 结论

**当前 Pavia、Chikusei 的六组正式 V3-stage3 训练，没有发现足以认定训练或结果失效的错误，现有证据不支持要求重训。** 六组均训练至 600 轮，权重与测试报告匹配；seed42 的两个数据集 ×4/×8 完整图像复测与原报告完全一致。

本次只在本审计目录新增脚本、诊断数据和报告，未修改正式实验的源码、配置、权重或已有报告。没有重新执行 600 轮训练。

## 2. 发现的问题

### 2.1 通用 `DynamicSpatial` 的推理缓存可能使后续反向失败

定位：[CAVE/Model/DynamicSpatial.py:21](../../../CAVE/Model/DynamicSpatial.py#L21)，尤其是缓存创建、保存和复用部分（21–52 行）。冻结实验 `model/DynamicSpatial.py` 中也保留同一实现。

可复现条件：先对新建算子在 `torch.inference_mode()` 下运行，让某个 HR/LR 几何对应的缓存首次生成；随后在同一个实例、同一几何上切回有梯度的训练并反向。缓存里的 FFT 核、索引或权重仍是 inference tensor，反向报错：

```text
Inference tensors cannot be saved for backward.
```

本次 CPU 复现成功，缓存中检测到九个 inference tensor。最小触发方式：

```python
op = DynamicSpatial()
x = torch.randn(1, 3, 16, 16)
with torch.inference_mode():
    op(x, (4, 4))
x.requires_grad_(True)
op(x, (4, 4)).square().mean().backward()
```

**当前六组正式训练不受此路径影响。** [正式入口 run.py:37](../../v3_stage3_restart_20261111/run.py#L37) 创建模型后把 `model.physics.spatial` 替换为 `MatchedSpatial`。该算子已经在缓存生成处使用 `torch.inference_mode(False)` 与 `torch.no_grad()`，本次 CPU/GPU 均实测“先推理预热，再训练反向”通过。

实验目录里的历史预检曾暴露同类缓存问题，[README](../../v3_stage3_restart_20261111/README.md) 已记录 2026-11-12 的修复，正式协议与六组训练使用修复版本。不能把修复前的预检异常认定为修复后正式训练中断。

CAVE 历史训练入口没有当前训练入口这种训练前 inference 健康探针流程；此次未找到归档训练被该条件触发的证据。但直接复用默认模型做“推理→继续训练”仍存在风险。

建议：在通用 `DynamicSpatial._geometry` 创建缓存的整个过程中关闭 inference mode，再覆盖“先推理、后反向”回归检查。不要直接修改已冻结实验中的文件；修复应放入新版本，并重新记录源码哈希。本次仅报告，未改动该实现。

### 2.2 正式指标规则声明了未裁剪结果，实际没有写出

## 3. 模型实现核查结果

### 3.1 阶段和残差连接与 V3-stage3 定义一致

- 前端为 HSI 双三次上采样后与 HR-MSI 拼接，VectorAttention ×3，再经 1×1 通道投影得到 64 维特征。
- Stage 1/2 执行 Regional 多分支融合和物理引导 GI，保留阶段输入残差。
- 只有 Stage 3 执行可变形采样增量：`Regional(F2) + sigmoid(a3) * (Deform(F2) - F2)`；随后进入物理引导 GI，并保留阶段输入残差。
- 三个阶段都保留 Regional 的 HR、中尺度、LR 与全局上下文四个分支；门控 softmax 沿四分支维度进行。
- 三个 GI 使用各自参数；中间重建头与物理引导模块由阶段共享。物理残差调制 Q/K，未发现错把它接成最终输出监督或额外物理损失。
- 重建头拼接 `F0,F1,F2,F3`，输出与上采样 HSI 相加。

前向 hooks 在 CPU/GPU 的两个数据集 ×4/×8 均显示：三个 Regional、三个 GI 各调用一次，只有第三阶段 Deformable 调用一次。

### 3.2 可变形采样和物理调制确实参与学习

使用真实最终权重反向测试：Stage 3 偏移预测层和九点权重预测层都有有限、非零梯度，三个 GI 的物理 Q/K 调制层都有有限、非零梯度。Stage 1/2 偏移层没有梯度，符合该变体关闭相应分支的设计。

六个最终 checkpoint 的 Stage 3 偏移层、权重层、物理 Q/K 调制层及共享中间重建头权重均已离开各自的零初始化状态。Stage 3 的 sigmoid 门控约为 0.048–0.054，接近初始 0.0474，但可学习且已变化。

门控较小不等于分支无效：实际作用还取决于 `Deform(F2)-F2` 的幅度。当前证据只能确认分支启用且在学习，不能用它替代消融实验来证明改进来自哪个模块。

Stage 1/2 的 Deformable 参数仍注册在 state_dict 和 optimizer 参数列表中，但不参与前向、没有梯度；这是额外参数存储，不是意外训练了三个可变形模块。统计参数量时应分别报告注册总参数与实际启用参数。

### 3.3 空间退化、伴随和内存优化检查通过

在 CPU/GPU、多尺寸与 ×4/×8 上，将 `MatchedSpatial` 与训练数据生成的空间退化直接对照，FP64 最大误差在 `3.4e-16` 以内；伴随内积误差在 `3.2e-15` 以内。采样相位、核宽和循环边界与当前数据协议一致。

双线性采样的 `(x,y)` 轴顺序、HR/LR 间距、有界偏移、九点 softmax、FP32 累积、border padding 和 `align_corners=False` 未发现接线或尺寸错误。

完整图像推理使用按行分块的 VectorAttention；分块分支与原实现的小样本对比最大绝对误差 `4.77e-7`。该优化只在 eval 大图像时生效。正式 ×4/×8 完整图像复测也通过。

六组均满足：

- 训练日志 epoch 连续为 1–600，每轮1000个 patch，累计600000个 patch、12000次 Adam 更新，没有缺轮或同轮覆盖迹象；本批没有 resume 记录。

- 最终 checkpoint 的模型状态可严格加载，配置与独立 config 一致；所有12份测试报告记录的 checkpoint 哈希与实际权重一致，逐图像均值及三种子均值/样本标准差重算一致。

微批次累积实现按 `micro_batch/effective_batch` 缩放梯度。模型没有引入跨样本 BatchNorm 或训练 dropout；本次以 true batch4 对比 micro batch2 累积两次，CPU 梯度相对误差约 `1.7e-7–2.1e-7`，GPU 约 `4.6e-7–5.3e-7`，符合浮点误差范围。正式 micro5×10 的缩放逻辑审阅无误；本次没有另做占用显存更大的 true batch50 对照。

**600轮不是600000次优化器更新。** 当前有效 batch50，每轮20次更新，所以总计12000次；CAVE 历史 batch1 协议同样600轮×1000patch，更新次数是600000。它们不可仅按“都训练600轮”认为训练预算相同。当前 SFNO 匹配基线与 V3-stage3 使用同样的批量、patch和更新预算。

## 5. 数据划分与评价口径

- 当前 Pavia、Chikusei 声明的训练矩形与 ×4/×8 测试矩形交叠像素数均为0；原始数据与固定响应文件哈希核对通过。
- 训练只在训练区域随机取64×64 patch并旋转、翻转；当前模型输入是 LR-HSI 和 HR-MSI。
- CAVE 为20个训练场景与12个测试场景，无场景重叠；归档光谱响应拟合声明使用的场景均来自训练集合。
- 健康探针是固定训练区域样本，没有使用最终测试区域决定停训或挑选 checkpoint。正式测试固定使用600轮最后权重，没有在测试集里挑“最好的一轮”。
- 测试异常传感器值按当前协议在测试 patch 内补齐后生成合成观测，异常位置不参与指标；原始 GT 非零掩码也参与评价。合成 LR/MSI 从测试 GT 生成属于本协议的退化仿真，不能直接据此认定为训练泄漏。
- 当前评价是各图像指标的算术平均，ERGAS 使用实际 sf。Chikusei ×4 测试500×500，而 ×8 为496×496；两者覆盖范围略有不同，协议已明确。可比较各自倍率下不同模型，不能把两倍率数值变化完全归因于尺度。

目前没有发现声明划分中的数据泄漏或当前 SFNO/V3 指标口径不一致。这不等于对所有历史数据处理过程作无条件保证。

## 6. 结果是否支持“正常训练并有改善”

同数据、同评价口径、同优化预算的当前 SFNO 基线与 V3-stage3，三种子结果如下。`±` 为样本标准差，非置信区间。

| 数据集 | 倍率 | SFNO PSNR/dB | V3-stage3 PSNR/dB | 均值差/dB |
|---|---|---:|---:|---:|
| pavia | ×4 | 44.7693 ± 0.2287 | 45.3999 ± 0.0530 | +0.6306 |
| pavia | ×8 | 43.6520 ± 0.2839 | 44.0672 ± 0.1566 | +0.4153 |
| chikusei | ×4 | 44.5961 ± 0.7464 | 46.3003 ± 0.2321 | +1.7042 |

上述四种设置中，V3-stage3 的平均 SAM 和 ERGAS 也均优于对应 SFNO 基线。结果支持当前设置下模型有学习且整体优于这套匹配基线；仅三个种子、两个当前遥感数据集不能证明任意场景或任意倍率都更好，也不能证明各新增模块各自的贡献。

## 7. 仍应明确的限制与后续事项

1. 通用 `DynamicSpatial` 的缓存问题需要在未来可训练版本修复；当前正式实验已有独立的修复路径，无需因为这个通用缺陷就重跑已完成六组。
2. CUDA `grid_sample`、adaptive average pooling 与抗混叠双线性下采样的反向会给出非确定性警告。配置明确使用 `warn_only=True`，所以同 seed 重新训练不保证逐位一致；本次完整推理复测一致不能推导训练反向完全确定。
3. 当前健康探针来自训练区域，只能检查训练是否明显失常；它不能替代独立验证集来证明没有过拟合。本协议固定600轮，并未声称通过验证集选择最优轮次。
4. 当前实际冻结空间算子明确只接收等轴整数 ×4/×8；本次检查只能证明这两个倍率通过。核心部分采用观测间距条件或神经算子形式，不代表这个训练入口已支持任意连续倍率。
5. 协议已声明这是在作者 MSI、精确测试坐标和完整训练配置不可得条件下的近似复现。结果只应在清楚说明的数据、响应、划分、训练预算与评价口径下比较。
6. 后续优先补充独立消融与计算成本测量，以区分区域融合、物理调制和第三阶段可变形修正的贡献；不能从本次正确性审计直接推出方法新颖性。
